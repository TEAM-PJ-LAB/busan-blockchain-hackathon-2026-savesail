# research — 측정·경제성 실험 (PRD 8장)

이 폴더의 코드는 SaveSail의 두 가지 주장을 숫자로 확인한다.

1. **측정**: 체인에 미리 고정한 무작위 ON/OFF 일정으로 잰 절감률은 편향이 없고, 하한으로 정산하면 투자자에게 과다 지급하지 않으며, 지급자·투자자 대표·검증기관이 할 수 있는 조작은 잡히거나 해가 없다(PRD 1.3절 M1~M10).
2. **경제성**: 그 측정 결과로 정산하는 구조에서 후순위 수익률, 선순위 손실 확률, 지급자 손익이 목표를 만족한다(PRD 1.4절 F1~F5).

## 재현

```bash
pip install numpy==2.5.3 scipy==1.18.1
python3 research/run_all.py                     # 전체(격자 R8·A·B·C·D → 판정 → 지급 비율 표 → 경제성)
python3 research/run_all.py --quick 20 --twice  # 축소판을 두 번 돌려 결과 파일 sha256이 같은지 확인
```

모든 난수는 (격자, 조건 번호, 반복 번호)로 시드를 잡으므로 같은 명령이면 같은 파일이 나온다. `run_all.py`는 단계별 실행 시간과 결과 파일의 sha256을 `results/run_all.json`에 남긴다. 전체 실행은 GitHub Actions `research` 워크플로가 20개 작업으로 나눠 돌리고(`.github/workflows/research.yml`), 결과를 `research-results` 브랜치에 올린다.

## 측정 방법 (채택안, PRD 7.2절)

- **설계**: 3시간 블록, 5블록(15시간) 그룹마다 OFF 1블록. OFF 위치는 세 참여자의 해시 체인 값을 합친 sha256으로 정해져 아무도 고를 수 없다. 블록 첫 15분은 전환 과도 구간으로 뺀다(첫 시간 가중치 0.75).
- **기준 모델**: log(무세일 연료)를 독립 속력(제3자 AIS + 해류 보정)·보고 흘수·재분석 맞바람 성분·재분석 파고의 자연 3차 스플라인으로 예측. 설치 전 데이터로만 학습.
- **추정치**: `r̂ = 1 − (ΣON 실제/ΣON 예측) ÷ (ΣOFF 실제/ΣOFF 예측)`. 같은 날씨·선체 상태가 ON·OFF에 무작위로 섞이므로 모델 오차가 상쇄된다.
- **신뢰구간**: 교차 적합 위약 보정. 설치 전 데이터를 시간순 5등분해 표본 밖 예측을 만들고, 거기에 캠페인과 같은 무작위 일정을 1,000번 가상으로 적용해 "효과가 없을 때 나오는 추정 오차" 분포를 잰다. 그 2.5·97.5% 분위수로 하한·상한을 만든다.
- **조작 검사**: 공변량 균형(속력·흘수·맞바람·파고와 보고값−독립값의 ON·OFF 차이, Newey–West 표준오차, z = 4), 연료/축동력 균형(엔진 시험 곡선으로 보정, z = 4), 항차별 연료 수급 서류(BDN) 대조(max(0.5%, 4σ)), 계측기 Ed25519 서명.

## 판정 기준

`judge.py`는 PRD 1.3절 기준표를 그대로 코드로 옮겼다. 기준은 팀이 먼저 정한 고정값이며 결과를 보고 낮추지 않는다. 기준을 벗어난 조건은 같은 조건을 다른 시드로 10,000회 다시 돌려 우연인지 확인하고, 그래도 벗어나면 방법을 고쳐 격자 전체를 다시 돌린다(PRD 10장). 결과와 수정 내역은 `results/`에 남는다.
